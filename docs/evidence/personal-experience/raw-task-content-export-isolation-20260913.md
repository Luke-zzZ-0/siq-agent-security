# M121 默认导出与原文仓隔离回归

日期：2026-09-13；任务：UX-013；规格：§3.12.30、ADR-048。

仓库当前没有遍历整个状态目录的通用诊断包；现有导出均从明确的结构化事实对象构建。本批把这一架构判断固定为四条可执行回归：在真实临时状态目录的 `raw-task-content/content/` 内写入唯一可识别哨兵，再执行 CLI 全局导出、管理 HTTP 全局导出、任务回执摘要和完整脱敏追溯包。四条输出都必须不含哨兵，也不得出现 `raw-task-content` 路径标记。

覆盖入口：

- `siq-agent-security export --out ...`
- `GET /v1/export`
- `GET /v1/task-activities/{id}/export`
- `GET /v1/task-activities/{id}/trace-export`

验证通过：

- 四项定向普通测试与 race 测试。
- `go test ./...`、`go vet ./...`。
- 变更文件 gofmt 无输出，`git diff --check` 无输出。

这些测试故意使用无效原文文件，证明默认导出不会因目录存在而读取、校验、报错或打包它。M118 的真实原文解密仍只在管理会话下通过单记录显式 POST 进行。本批没有新增产品二进制逻辑，因此沿用 M120 的最终四目标构建结果。

边界：未来如果新增支持诊断包、崩溃报告、日志采集或任意状态归档，该新入口必须先增加同类哨兵排除测试；本批不能替未来尚不存在的收集器提供保证。原生适配器采集、自动到期清理和真实平台原文端到端仍待完成。本批未提交、推送或合并。

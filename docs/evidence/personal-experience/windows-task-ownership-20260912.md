# M74：Windows 任务签名归属与准备恢复

日期：2026-09-12。候选：`codex/personal-macos-stop-recovery`，基于 `274ed97` 的本地增量。规格 §3.11.36；合同 `local-windows-task-record/v1`。本批没有注册或启动 Windows 系统任务。

`task-prepare` 使用当前用户的 SID 和固定任务 XML，在生命周期锁与主 Writer 下先排他发布签名意图，再发布 XML。记录绑定实例、规范状态目录身份、任务名、用户 SID 和 XML SHA-256。重复准备仅接受完全匹配的记录；已有签名记录但 XML 缺失时可恢复相同内容。只读核验不修复文件。
